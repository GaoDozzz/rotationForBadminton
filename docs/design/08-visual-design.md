# 品牌与界面视觉规范

## 1. 品牌方向

品牌名暂定“转转接龙”，关键词为：轮转、公平、轻松组局、现场清晰。视觉不复刻参考产品，保留其信息流程，重新建立羽毛球运动识别。

Logo 建议采用“环形轮转箭头 + 羽毛球头部”的组合符号；小尺寸下优先保证轮转符号清晰。

## 2. 色彩

| 用途 | 色值 | 使用说明 |
|---|---|---|
| 品牌主色 | `#16A66A` | 主按钮、本人比赛、激活状态 |
| 活力强调 | `#FF8A34` | 当前轮次、关键数字、待处理提醒 |
| 信息蓝 | `#3478F6` | 链接、下一场、普通信息 |
| 警告 | `#F4A11A` | 待确认、候补、重排影响 |
| 危险 | `#E5484D` | 取消、移除、比分冲突 |
| 主文字 | `#1F2937` | 标题和正文 |
| 次文字 | `#667085` | 辅助说明 |
| 页面背景 | `#F5F7F6` | 页面背景 |
| 卡片背景 | `#FFFFFF` | 内容容器 |

颜色不能作为状态的唯一表达方式，必须搭配图标或文字。

## 3. 字体与尺寸

- 使用微信系统字体，不内置大体积字体文件。
- 页面标题 36rpx/600，卡片标题 32rpx/600，正文 28rpx/400，辅助文字 24rpx/400。
- 比分数字 56～72rpx/700，强调现场可读性。
- 最小可点击区域 88rpx × 88rpx。
- 卡片圆角 20rpx，页面横向留白 24～32rpx，组件间距使用 8rpx 基数。

## 4. 导航

应用级导航为首页、发起、我的。球局详情内使用吸顶四页签：比赛、排名、对阵、裁判。计分、管理和重排使用标准导航栏返回。

## 5. 关键组件

### 球局卡片

- 显示日期时间、状态、名称、场馆、正式/候补人数和水平。
- 组织者球局显示管理标识；本人有下一场时突出下一场信息。

### 人员头像

- 头像 + 昵称 + 性别符号，水平作为弱标签。
- 代报名且未绑定账号时显示“代”角标。
- 头像缺失时显示昵称首字占位。

### 对阵卡片

- 左右两队对称布局，中间显示 `VS` 或比分。
- 顶部明确轮次和场地，右侧显示状态。
- 本人头像外圈使用品牌主色，不改变整张卡片底色。

### 排名行

- 积分是第一视觉数字，同时展示胜负、总得分和失分。
- 并列名次使用相同名次数字，不通过列表序号误导。

### 计分器

- 两队区域固定左右位置，避免加分时视觉跳动。
- 加分为主按钮，减分弱化且需防误触。
- 首版一局制只显示“完成计分”，不显示“下一局”。
- 提交前展示完整比分和球员名称二次确认。

## 6. 状态呈现

| 状态 | 标签文案 | 视觉重点 |
|---|---|---|
| 报名中 | 报名中 | 主色 |
| 候补 | 候补第 N 位 | 警告色 |
| 待开赛 | 待开赛 | 信息蓝 |
| 进行中 | 进行中 | 活力橙 + 动态圆点 |
| 待确认 | 比分待确认 | 警告色 |
| 比分争议 | 比分有争议 | 危险色 |
| 已完成 | 已完成 | 成功色 |
| 已取消 | 已取消 | 中性灰 |

## 7. 空、错、加载状态

- 无球局时提供“发起第一场球局”主行动。
- 对阵未生成时解释需要组织者生成。
- 排名无比分时说明“完成第一场比赛后生成排名”。
- 骨架屏结构与最终卡片一致。
- 错误提示给出重试、刷新或联系组织者等下一步动作。

## 8. 分享视觉

分享卡片包含品牌符号、球局名称、日期时间、场馆、人数、候补状态、水平要求、报名截止和“加入接龙”行动文案。

不得展示完整参赛名单、个人积分或其他非必要个人信息。

## 9. 适配与可访问性

- 设计基准宽度 750rpx，同时检查 320px 小屏。
- 适配顶部安全区和底部 Home Indicator。
- 文本与背景对比度按 WCAG AA 方向检查。
- 支持系统字体放大后的卡片自适应高度。
- 动效控制在 150～250ms，不让动画阻塞操作。
